# Keen 4 Amiga 0.1.0 release notes

The package contains the 68040 FPU RTG Keen 4 binary, twelve Keen 4 support files, the installer, source snapshot, build record, licenses, and user README. It omits game data, ROMs, AmigaOS and drivers. Each archived file has a size and SHA-256 entry in **manifest.json**. The package's binary is checked against **build/amiga/build.json** before it is written.

The binary with SHA-256 **4588697409bcfc67daaa886b1e39269ba48c6b533a5711e03864a10cd6bf945c** has user-confirmed gameplay, sound and joystick directions on an A1200 with PiStorm32-Lite and CM4. It includes the SDL joystick-axis normalization for digital values of +/-257. Full playthrough, hardware save/load and long sessions remain unverified. Guest and host checks are recorded in [amiga.md](amiga.md).

The package is a release candidate and has not been published. The matching SDL source is archived from [AmigaPorts/SDL_old](https://github.com/AmigaPorts/SDL_old) at commit **eb484f4a1b70257f962c295647ad262c8257c1dd**. Its tarball SHA-256 is **cabd9f29949aa4c2fc3ad15f54cc188314b0fe33f6892cb89c37d348ceabbfff**. Rebuilding it in the pinned toolchain image with SOURCE_DATE_EPOCH=1762646400 produced **libSDL.a** SHA-256 **0e5af159ddb3d7d8a39636fbab2818dd1e94d9746e85a33b1d682d81780feed9**, matching the library used by the game. Relinking the game from the packaged source and rebuilt library produced binary SHA-256 **4588697409bcfc67daaa886b1e39269ba48c6b533a5711e03864a10cd6bf945c**, matching the release binary. The archive also includes SDL's notice and LGPL text. **manifest.json** records this source and relink verification separately from hardware coverage and publication status.

To reproduce the archive, use **make build**, then set **LHA_COMMAND** to an LHa compressor and run **make package-amiga**. The build script checks its pinned toolchain inputs; source and binary hashes are in **build.json**. For an archive at another path, pass **--output** to **scripts/package-amiga.py**. The source snapshot includes the port code, Keen 4 support files, the SDL source tarball, and scripts to rebuild SDL and relink the game. The toolchain image is external. The relink script accepts a modified **libSDL.a** and writes **build/amiga/relinked/omnispeak** without changing the packaged binary or build record.

On 2026-09-28, the source extracted from the final LHA reproduced both the SDL library and game binary hashes above. The 52 host tests passed. Amiga LhA 2.15 extracted all 150 payload files with matching manifest hashes. Installer 43.3 installed the user README and removed the obsolete hardware guide while preserving saves, configuration and a custom drawer icon. This scripted upgrade check used preset requester answers (**run-fc84f80c**); it did not repeat gameplay testing.

The revised candidate has Keen artwork on **Install** and **Start-Keen4** and uses the configured system drawer icon for **Keen4**. In the scripted guest check (**run-c72e7317**), Installer 43.3 extracted all 149 files with matching manifest hashes. It replaced the exact icon shipped by the earlier candidate with the configured default and preserved a separately positioned custom icon on reinstall. The Amiga icon library read both 64x40, two-plane tool icons with their intended tools and stack sizes. The current 64x56 **Start-Keen4** artwork adds normal and selected GlowIcon images with embedded palettes while retaining the two-plane fallback. Its GlowIcon data has host-side format, rendering and package coverage; it has not been checked on the guest. This check did not repeat gameplay testing.
